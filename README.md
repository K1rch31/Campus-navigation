# Мобильный гид по кампусу с навигацией

## О проекте

Campus Navigator — веб-приложение для навигации первокурсников по корпусам университета. Проект помогает студентам ориентироваться на территории кампуса и находить нужные помещения.

Приложение разработано с использованием Next.js. Для запуска проекта используется Node.js и npm.

## Как запустить локально

1. Клонируй репозиторий:

   ```bash
   git clone https://github.com/K1rch07/Campus-navigation.git
   ```

2. Перейди в папку проекта:

   ```bash
   cd Campus-navigation/Проект
   ```

3. Установи зависимости:

   ```bash
   npm install
   ```

4. Запусти приложение:

   ```bash
   npm run dev
   ```

5. Открой в браузере адрес:

   http://localhost:3000
